ยินดีต้อนรับเข้าสู่เว็บไซต์เเฟ้มสะสมผลงานของ นายชนาธิป จึงสงวนสิทธิ์
1.สวัสดีครับ กระผมชื่อ ชนาธิป จึงสงวนสิทธิ์ 
ชื่อเล่นชื่อ อาร์ตี้ ตอนนี้กระผมอายุ17ปี ปัจจุบันอาศัยอยู่ที่อำเภอบ้านบึง จังหวัดชลบุรี
2.กระผมจบการศึกษามัธยมศึกษาตอนต้นมาจากโรงเรียนบุญประทีปวิทยาคาร ตอนนี้กระผมกำลังกำลังศึกษาอยู่ในระดับชั้นมัธยมศึกษาตอนปลาย โรงเรียนบ้านบึง"อุตสาหกรรมนุเคราะห์" อำเภอบ้านบึง จังหวัดชลบุรี
3.สิ่งที่ผมชอบทำหรืองานอดิเรกของผมคือ เล่นเปียโน,ตีเเบตมินตัน,อ่านหนังสือเเละออกกำลังกายทั่วไปเป็นประจำ
4.ประสบกาณ์/ความเชี่ยวชาญ กระผมมีความสามารถในการตัดต่อคลิปวิดีโอ การทำเเผล รวมถึงการปฐมพยาบาลเบื้องต้น
นอกจากนี้กระผมยังมีความสามารถในการทำอาหารอีกด้วย
5.มหาวิทยาลัย/คณะที่ผมอยากเข้าคือ มหาวิทยาลัยมหิดล/คณะเเพทยศาสตร์ เพราะผมมีความฝันตั้งเเต่เด็กๆเเล้วว่าอยากเป็นหมอเพื่อที่จะได้ช่วยเหลือคนที่บ้านของผมที่เจ็บป่วย และตั้งใจไว้ว่าจะต้องหาเงินมาเลี้ยงครอบครัวของผมให้ได้
6.ข้อดีเเละจุดเเข็งของผม ถ้าพูดถึงตัวตนของกระผม เพื่อนๆมักบอกผมว่าเป็นคนเงียบๆ เเต่เรียนเก่ง ทำงานครบเสร็จทันเวลางาน สไตล์การทำงานของกระผมจะเป็นคนที่ชอบวางแผนไว้ล่วงหน้า และชอบเรียนรู้จากความผิดพลาดเสมอ
7.ความสำเร็จที่น่าภาคภูมืใจของกระผม คือการได้เข้ามาศึกษาต่อในระดับชั้นที่สูงขึ้น นับเป็นก้าวเเรกของตัวกระผม ดังนั้นกระผมจะพยายามเรียนให้สูงๆอีกยิ่งขึ้น
8.สิ่งที่กระผมกำลังสนใจอยู่ในตอนนี้คือ กระผมคิดจะพัฒนาทักษะSoft skill เเละทักษะการใช้ภาษาต่างประเทศของกระผม เพื่อที่จะสามารถเพิ่มรายได้ให้กระผมอีกยิ่งขึ้น
9.คติประจำใจของกระผมคือ"ความพยายามอยู่ที่ไหน ความสำเร็จอยู่ที่นั่น" ซึ่งเป็นคติที่กระผมยึดถือเเละปฏิบัติเรื่อยมาตั้งเเต่เด็กจนถึงปัจจุบัน
10.สุดท้ายนี้กระผมขอบพระคุณเป็นอย่างมากที่อ่านประวัติส่วนตัวของกระผม หลังจากนี้ถ้ามีเรื่องไหนที่สามารถแชร์หรือ ช่วยเหลือกันได้ สามารถทักมาคุยกับกระผมได้นะครับ สามารถติดต่อกระผมได้ทาง
