ยินดีต้อนรับเข้าสู่เว็บไซต์เเฟ้มสะสมผลงานของ นายชนาธิป จึงสงวนสิทธิ์
สวัสดีครับ กระผมชื่อ ชนาธิป จึงสงวนสิทธิ์ ชื่อเล่นชื่อ อาร์ตี้
ปัจจุบันกำลังศึกษาอยู่ในระดับชั้นมัธยมศึกษาปีที่6 โรงเรียนบ้านบึง"อุตสาหกรรมนุเคราะห์"
สิ่งที่ผมชอบทำหรืองานอดิเรกของผมคือ เล่นเปียโน,ตีเเบตมินตัน,อ่านหนังสือ เเละออกกำลังกายทั่วไปเป็นประจำ
มหาวิทยาลัย/คณะที่ผมอยากเข้าคือ มหาวิทยาลัยมหิดล/คณะเเพทยศาสตร์ เพราะผมมีความฝันตั้งเเต่เด็กๆเเล้วว่าอยากเป็นหมอเพื่อที่จะได้ช่วยเหลือคนที่บ้านของผมที่เจ็บป่วย และตั้งใจไว้ว่าจะต้องหาเงินมาเลี้ยงครอบครัวของผมให้ได้
